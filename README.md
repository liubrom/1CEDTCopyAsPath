# Копировать как путь для 1С:EDT

Плагин добавляет команду **«Копировать как путь»** в контекстное меню **навигатора метаданных** и **текстового редактора** 1С:EDT.  
В навигаторе — подменю с путями к папке объекта, модулям, формам, командам и макетам.  
В редакторе — ссылка на файл и строку(и) с кодом. Пути копируются **в кавычках** (удобно для Windows 11).

Поддерживаются конфигурация, расширения, внешние отчёты и обработки EDT.

**Версия:** 1.01

---

## 1. Установка

Устанавливается из репозитория штатными средствами EDT (**Справка → Установить новое ПО…**):

> https://liubrom.github.io/1CEDTCopyAsPath/

Либо из zip-архива в разделе [Releases](https://github.com/liubrom/1CEDTCopyAsPath/releases) (`copy-as-path-plugin-1.0.1.zip`).

**Шаги в EDT**

1. *Справка → Установить новое ПО…*
2. *Добавить…* → указать URL репозитория **или** выбрать zip
3. Отметить **Copy As Path for 1C:EDT** / **Копировать как путь для 1С:EDT**
4. Далее → принять лицензию → *Перезапустить сейчас*

Проверка: *Справка → О программе → Сведения об установлении* — должна быть запись `Copy As Path for 1C:EDT`.

## 2. Использование

1. В дереве метаданных выделить объект (документ, форму, команду, макет, корень коллекции «Документы» / «Отчёты» и т.д.).
2. ПКМ → **Копировать как путь**.
3. Выбрать пункт подменю — путь попадёт в буфер обмена.

Для объекта метаданных пункты сгруппированы: папка и модули → файл `.mdo` → формы → команды → макеты → все файлы.

Команда **не показывается** для реквизитов, табличных частей и корня проекта.

### В редакторе файла

1. Открыть файл в текстовом редакторе EDT (`.bsl`, `.form`, `.mdo` и др.).
2. ПКМ на строке или выделенном фрагменте → **Копировать как путь**.
3. В буфер попадёт ссылка вида `"E:\путь\к\файлу", Строка 42, ТекстСтроки`.

Правила:

| Ситуация | Результат |
|----------|-----------|
| курсор на строке | `"путь", Строка N, полный текст строки` |
| пустая строка | `"путь", Строка N` (без кода) |
| выделение 1 строки | `"путь", Строка N, полный текст строки` |
| выделение 2–10 строк | `"путь", Строки N-M,` затем полные строки с переносами |
| выделение 11+ строк | `"путь", Строки N-M` (без кода) |

Фрагмент выделения не копируется — всегда **целиком затронутые строки**.
